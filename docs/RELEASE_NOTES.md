# 玲珑 1.0.0

Windows 10/11 x64 桌宠。下载 `Linglong-Setup-1.0.0.exe`，安装后打开桌面上的「玲珑桌宠」。安装包尚未签名。

- 可爱「小玲」、成熟「玲月」两套透明形象，共 16 个动作画面。
- 左键连接 Nano 当前默认节点，验证网络后打开 Codex；拖动改变位置，透明区域穿透。
- 右键切换形象、蹲下、吃饭、摸头、挥手、睡觉、查看连接和额度。
- 默认开启当前用户的开机自启动；可关闭，支持置顶、大小调整、安静模式、托盘隐藏与恢复。
- 通过官方 Codex app-server 查询真实额度，并保留历史数据来源和更新时间。

Nano 要求管理员权限时，需在 Windows UAC 提示中确认。自动连接只操作明确识别出的「连接」按钮；停留在节点选择等页面、文字无法识别或取消授权时，会提示在 Nano 首页手动连接，并等待 30 秒继续启动 Codex。不会选择其他节点。当前连接复用、Codex 打开和实时额度已经实测；没有为了测试冷启动而强制断开现有网络。

Nano 流量余额请在 Nano 内查看；桌宠显示的 Codex 百分比不是付费账户余额。

偏好和应用路径留在本机，公开仓库不包含参考原图、账户信息、Nano 配置和私人会话。
