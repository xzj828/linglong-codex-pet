# ChatGPT 桌宠 1.1.0

- 桌宠名称统一为 **ChatGPT**，形象只分 **可爱 / 成熟**。控制面板、角色脚下名称、右键菜单、托盘和快捷方式同步更新。
- 显示本机 Codex 的工作状态：任务进行中切换忙碌动作，完成显示完成动作，中断显示已停止；气泡和小窝面板同步更新。互动结束后回到当前工作状态。
- 大小范围扩大为 **25%–300%**，增加常用比例按钮。小尺寸保持气泡文字可读，大尺寸自动适应屏幕工作区。
- 按新的三视图重绘可爱与成熟形象的 8 种动作，补齐紫色龙翼、角纹、尾巴与结形发饰；保留之前长裙的层叠薄纱和白紫配色。
- 保留 1.0.1 的 Windows 加密目录保存修复，以及现有配置和开机自启动。

状态根据本机最近会话记录判断，已跟踪会话约 2 秒更新一次，新会话发现最长约 10 秒；长时间无新记录或无法可靠读取时显示未知，不推测已经完成。远程主机和未写入本机会话记录的任务不在监测范围内。不展示聊天正文。

下载 `ChatGPT-Pet-Setup-1.1.0.exe` 覆盖安装即可。项目仍为独立开源桌宠，与 OpenAI、Nano 无隶属关系。
